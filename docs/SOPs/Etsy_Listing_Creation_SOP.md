# Etsy Listing Creation SOP
**Version:** 1.0

## Goal
Create 5 new Etsy listings per day using QuoteForge templates.

## Step 1: Choose Niche (2 min)
1. Open QuoteForge → **Catalog & SEO** tab
2. Review Phase 1 validation checklist
3. Pick an undercreated niche from the list

## Step 2: Get SEO Pack (1 min)
1. In Catalog & SEO tab → SEO Pack Generator
2. Select the niche
3. Click Generate SEO Pack
4. Copy the title and tags

## Step 3: Create Design (10 min)
1. Open Canva → Your templates
2. Select a scenic template (mountain/beach/forest/flowers)
3. Add an appropriate quote from the QuoteForge library
4. Export PNG at 300 DPI

## Step 4: Create Gelato Product (5 min)
1. gelato.com → Stores → Your Etsy store → Add Product
2. Select: Poster → 18x24 in
3. Upload your PNG
4. Preview mockup
5. Set price (see profit calculator for guidance)
6. Publish to Etsy

## Step 5: Optimize Etsy Listing (5 min)
1. In Etsy, find the new listing
2. Replace the auto-generated title with your SEO title from Step 2
3. Paste the 13 tags (one per tag box)
4. Write description: use the 2-sentence hook + add 3-4 sentences about personalization
5. Add the Personalization Box text (from QuoteForge Order Processor → Copy Etsy Form)
6. Set shipping: free shipping (include in price) OR $4.99 flat

## Daily Goal: 5 listings = 150/month = 1,800/year
